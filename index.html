Enviar a vitrine para as clientes

1. Lista de clientes

Uma cliente por linha: Nome, telefone com DDD. Pode colar direto de uma planilha.

2. Mensagem

Use {nome} para o primeiro nome da cliente e {link} para o link da vitrine.

Link da vitrine

3. Enviar

Toque em Enviar em cada cliente: o WhatsApp abre com a mensagem pronta, é só apertar enviar. Ao voltar, passe para a próxima.

Por que um toque por cliente? O WhatsApp não permite que um site dispare mensagens sozinho para várias pessoas, e números que fazem isso por programas não oficiais costumam ser bloqueados. Para envios 100% automáticos, o caminho seguro é a API oficial do WhatsApp Business (Meta). Outra opção gratuita: no app WhatsApp Business, crie uma Lista de transmissão e cole o link da vitrine; chega para todas as clientes que têm o seu número salvo.
